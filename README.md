##Comandos Básicos para Maquetado de la Documentación utilizando el estandar de Markdown (.md)
---
;

Markdown es el estándar utilizado por  Git y GiThUB , para estilizar(maquear) la documentacion de proyectos , lo que permite al usuario  y colaboradpores  del proyecto entren en contexto y operación del mismo 

###$1. Encabezados o Titulos (HEADERS) 
Para podeer realizar  una buena documentación del proyecto debemos distribuir correctamente los contenidos , para poder delimitar  o hacer énfasis (enfatizar), es decir,resaltar las secciones más importantes , podremos utilizar las siguientes :

**Ejemplos**
# Encabezado de nivel 1
## Encabezado de nivel 2
### Encabezado de nivel 3
#### Encabezado de nivel 4
####  Encabezado de nivel 5
#####  Encabezado de nivel 6
###### Encabezado de nivel 7 *El estándar solo permite  6 niveles  para titulo,apartir del séptimo seran presentados con texto plano (sin estilo)*
### 2. Separadores  (SEPARATIONS)
si se desea marcar una separación visual de los contenidos podemos utilizar una linea horizontal indicando tres caracteres  - continuos , en el maquetado  

***EJEMPLO***

### Título de la sección
